**AI 把 18 位传奇一块体素一块体素地重建出来，然后让你和他们同场。**

整支片围绕 aiBA 真正有的三件"AI"展开，不编造功能：

| 游戏里的真实能力 | 片中的呈现 |
|---|---|
| 18 位体素球星（`LEGENDS`），每人有自己的投篮弧线与出手风格（`SHOT_PROFILES`） | 在数字虚空中被扫描重建，名片 HUD 显示号码 / OVR / 弧线 / 出手风格 |

| RACK RUSH、世界奇观球场、绝杀时刻、全球排行榜 | 快切蒙太奇 + 绝杀高潮 + 结尾功能芯片 |

## 视觉语言

- **两个世界**：「数字虚空」（黑底、青色网格地面、数据光柱、全息线框）↔「真实球场」（游戏本体场景）。重建完成的那一拍，虚空翻成球馆。
- **全息重建**：球员从脚到头被一道扫描环"打印"出来——环下是实体，环上是青色线框。
- **HUD**：细线角框、追踪框、数据流、弹道预测虚线、命中概率。字体 Orbitron，色 青 `#77e7ff` / 金 `#ffd23f` / 绿 `#7CFC6B` / 红 `#ff4040`。
- **像素**：3D 以 960×540 渲染 ×2 最近邻放大，保留方块质感；再叠一层柔光（bloom）和扫描线。
- **卡点**：每个重拍 = 震动 / 冲击推镜 / 色差分离，两次 DROP 用反相冲击帧。

## 修订原则（v4）

- **没有静止的人**：每位球星都在做自己的动作（投篮 / 运球 / 胯下 / 转球 / 拉伸 / 撒粉 / 指天…），亮相与阵列用慢动作捕捉。
- **群像不同步**：每人固定相位、各自招牌动作；庆祝时各有各的庆祝方式。
- **出手严格同步**：一律按游戏节奏，蓄力到 ph = 1.0 那一刻松手，球从真实手部位置起飞，之后是跟随动作和落地。
- **NBA 75 大多给镜头**：库里、乔丹、科比、艾弗森、伯德、哈登、利拉德、雷·阿伦、雷吉·米勒；其余球星半拍带过。
- **你 = 库里**：百分大战和绝杀时刻里，你操控的是库里。
