# 动画指南

分镜说"拍什么"，这份说"怎么动"。代码里所有常量都能在这里找到出处。

## 1. 画面质感

- **纸**：暖米色纸底 `#f2e8d5`，一张静态纸纹（纤维 + 颗粒）乘在最上层。纸纹不动，避免满屏噪点吃码率。
- **水彩**：背景、爆炸、火焰这些大面积颜色用 p5.brush 的 `fill()`（带晕染、边缘积色）**预烘焙**成贴图（`src/02-bake.js`），逐帧只做位移缩放。
- **墨线**：角色、道具、速度线全部用 p5.brush 的 `pen` / `marker` / `charcoal` 逐帧现画。
- **线条抖动（line boil）**：随机种子每 2 帧换一次（一拍两张），线条像手绘动画一样"活着"，但动作本身仍是 30fps 流畅运动。
- **平涂**：角色固有色用 `wash()` 平涂 + 墨线压边，和水彩背景形成层次。
- **网点 / 漫画格**：慢动作和绝杀段加网点阴影、粗黑分格边框。

## 2. 色板

| 名 | 值 | 用在 |
|---|---|---|
| 纸 | `#f2e8d5` | 底 |
| 墨 | `#17120f` | 所有线 |
| 球橙 | `#ff6a1a` | 球、小方球衣、热血 |
| 血红 | `#e8233a` | 头带、印章、倒计时 |
| 青 | `#19c3d0` | aiBA 赛博感、零号、姿态骨架 |
| 洋红 | `#ff2e88` | 霓虹、爆炸 |
| 黄 | `#ffd23f` | 高光、星光、彩纸 |
| 夜蓝 | `#1b1d3a` | 绝杀段背景 |

暖色 = 小方，冷色 = 零号。高潮时两者对撞。

## 3. 动作原则

- **预备 → 动作 → 缓冲**：每个投篮都有下蹲（2–4 帧）、出手（1–2 帧急速）、跟随手型停留。
- **缓动**：出场用 `easeOutBack`（冲过头回弹），砸落用 `easeInCubic`，镜头推拉用 `easeInOutQuint`。
- **Hold**：重拍落点后停 2–4 帧再动，让观众"看清"。
- **Smear 残影**：快速挥臂、甩球时画 3 层半透明残影 + 拖尾墨线。
- **Squash & stretch**：球落地压扁 30%，弹起拉长 15%。
- **表情**：小方的眉毛、眼睛、嘴是独立参数（`brow` / `eye` / `mouth`），每个镜头至少一次表情变化。

## 4. 镜头语言

| 手法 | 用在 | 实现 |
|---|---|---|
| 猛震 shake | 每个 ★ 重拍 | 衰减正弦，6–8 帧 |
| 冲击推镜 punch-in | 片名、爆发 | 1 帧内缩放 +8% 再回弹 |
| 甩摇 whip pan | S1→S2、换场 | 3 帧横向位移 + 方向模糊线 |
| 升降 crane | S2 | 从鞋到脸，`easeInOutCubic` |
| 视差横移 | S7、S11 | 前中后三层不同速率 |
| 冲击帧 impact frame | 拍8、拍50 | 1–2 帧黑白反相 |
| 笔刷擦除转场 | S3→S4、S12→S13 | 巨型 marker 横扫 |

## 5. 分层（每帧从后往前）

1. 预烘焙水彩背景（原生 `image()`）
2. 远景墨线（`brush`）
3. 角色 + 道具（`brush.wash` 平涂 + `brush` 墨线）
4. 特效：速度线、墨点、冲击环
5. 2D 合成层：文字、闪白、反相、纸纹、暗角、镜头震动

p5.brush 的笔触是延迟合成的（换颜色才把上一种颜色落到画布），所以层与层之间显式调用 `flush()`，保证原生绘制和笔刷绘制的前后顺序正确。

## 6. 渲染

- `render.mjs`：本地静态服务 → Playwright 无头 Chromium → 先烘焙水彩贴图 → 多个页面并行逐帧渲染 → JPEG 管道进 ffmpeg（x264，CRF 21）→ 合成音轨。
- 同一帧号永远画出同一张图（所有随机数都由帧号播种），并行、断点续渲都安全。
