# 动画指南 ——「NEURAL COURT」

分镜说"拍什么"，这份说"怎么动、怎么拍、怎么做到每一帧可复现"。

## 1. 两个世界

| | 数字虚空 | 真实球场 |
|---|---|---|
| 用在 | A 开机、B 名单、D2 DNA、D3 VS、H 结尾 | C 片名、D1 体感、E 对战、F 绝杀、G 庆祝 |
| 组成 | 黑底 + 两层青色网格 + 140 根数据光柱 + 雾 + 独立三盏灯 | 游戏本体场景（`applyScenePreset`），观众、灯光、篮筐都是真的 |
| 切换 | `TR.setVoid(true)` 把游戏场景的顶层节点全部隐藏，只留演员/球/虚空组 | 每个镜头开头 `resetShot` 先还原 |

虚空 → 球馆只在拍32（DROP#1）发生一次，配反相冲击帧，是全片最大的"世界切换"。

## 2. 全息重建（TR.holo）

每个球员启动时记录自己每块体素在站姿下的高度。每帧给一个扫描高度 `scan`：

- 低于 `scan`：原材质（实体）
- `scan` 附近 9cm：亮青白色（打印头）
- 高于 `scan`：青色线框（尚未重建），或直接隐藏

扫描环 `TR.ring` 同步贴在扫描高度。`TR.wire` = 全身线框（DNA 未匹配者、结尾阵列）。

## 3. 动作（v4：没有静止的人）

- **动作库 `src/08-acts.js`**：投篮、运球、胯下、指尖转球、拉伸、撒粉、指天、挥手、振臂、怒吼、挥拳、鼓掌、秀肌肉、防守滑步、起跳；每位球星有自己的招牌动作（`TR.SIGNATURE`）和庆祝动作（`TR.CELEBRATE`），并有固定相位，所以群像里谁也不和谁同步。
- **慢动作**：亮相、阵列、DNA、特写都把动作时间慢放（0.25×–0.5×），画面右下角标 `SLOW-MO`。
- **投篮同步**：严格照游戏节奏——蓄力 ph 0→1 到最高点，随后 0.105s 伸肩肘送球，**第 0.092s 球离手**（与游戏 `shot-motion.js` 的 BALL_RELEASE_AT 同值），再压腕、手指下垂、保持 0.24s、0.38s 收回；身体 0.34s 内落地。手臂跟随直接调用游戏的 `applyShotFollowThroughPose`（三分大赛过场里 AI 用的同一套）。对战里每一投的球独立飞行，跨剪辑继续，入网后比分才跳。
- **热身扣篮**：直接调用游戏的 `pregameAnimate(actor,"dunk")`（Air Jordan 风格，含挂框摆动）。
- **头部**：`headRoot` 的原点在脚底，俯仰必须绕脖子 y=1.45 转（`TR.head`），否则头会甩离身体。
- **绝杀时刻（实机）**：`src/07-live.js` 把游戏时钟换成固定 1/30s，每帧调用游戏自己的 `animate()`；球到手后照 `trailer-capture.js` 的逻辑按住蓄力、到理想力度松手。第一人称、5v5 跑位、包夹、分球、封盖、蜂鸣、结果反应全部是游戏原生。

## 4. 镜头（没有静止机位）

| 手法 | 用在 |
|---|---|
| 低机位环绕 + 扫描 | A |
| 长廊高速前推（4 m/拍） | B1 |
| 升降拉远揭示阵列 | B2 |
| 绕篮筐低机位环绕 + 升 | C2 扣篮 |
| 弧线 + 升降 + 推近（组合） | D1 体感 |
| 推轨横移 → **希区柯克变焦**锁定科比 | D2 DNA |
| 每张特写都绕主体 60–80° + 推近 | D3 |
| 你出手：越肩 → 升起跟球摇向篮筐；对手出手：仰拍环绕 | E1 |
| **子弹时间**（球离手后时间冻结、环绕 276°）→ 追球 → **希区柯克变焦**入网 | E2 |
| 推轨滑轨 / 跨场景环绕 | E3 |
| 360° 升降环绕 | G1 |
| 甩镜入画 + 环绕推近 | G2 |
| 低机位上升快速环绕 | G3 |
| 升降 + 慢弧 | H |

`TR.vertigo(target, dir, fov, width)`：保持目标平面画面宽度不变，fov 变化时沿 dir 推拉机位。

庆祝段的球员围成两圈，镜头穿过人群时 `TR.clearNear` 会隐藏离镜头太近的人，避免穿模遮挡。

## 5. HUD（全部在 1920×1080 的 2D 层，保持锐利）

- 数据雨、开机终端、重建进度条
- 追踪角框 + 球星名片（真实姓名 / 号码 / OVR / 游戏里的弧线与出手风格）
- DNA：匹配度滚动 → 锁定，左侧 33 点姿态骨架
- 弹道预测虚线 + 弧线标签；命中概率表
- 比分牌、对手名片、世界球场名片、功能芯片

## 6. 合成

3D 960×540 → ×2 最近邻放大 → bloom（1/4 尺寸模糊 screen 叠加）→ 色差分离（重拍）→ 扫描线 → 暗角 → HUD → 马赛克/反相/闪白/淡出。

## 7. 可复现渲染

启动前固定 `Math.random`，启动后冻结游戏循环；按镜头分配给渲染进程，每个镜头从首帧顺序模拟。
