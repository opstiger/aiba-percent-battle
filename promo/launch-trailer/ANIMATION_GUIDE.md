# 动画指南（体素像素版）

分镜说"拍什么"，这份说"怎么动、怎么拍、怎么做到每一帧可复现"。

## 1. 画面语法

- **像素**：3D 渲染 640×360，×3 最近邻放大到 1920×1080。转场时再降到 80×45 / 40×23 做马赛克。
- **体素**：场景、观众、球员全部来自游戏本体，不画替代品。
- **HUD**：只在 1920×1080 的 2D 层画，保持锐利。样式照抄游戏：`rgba(10,14,24,.88)` 黑底、`#283750` 描边、Orbitron 900、3px 纯黑硬投影。
- **扫描线**：每 3 像素一条 18% 黑线（游戏的 `#scan` 叠层），外加暗角。
- **像素粒子**：金色方块粒子（3×3 / 6×6 像素），用在冲击、Logo、爆发。

## 2. 色板（游戏 `styles.css` 里出现频率最高的几个）

| 名 | 值 | 用在 |
|---|---|---|
| 金 | `#ffd23f` | 主标题、比分、粒子 |
| 青 | `#77e7ff` | 主角、姿态骨架、选中态 |
| 绿 | `#7CFC6B` | 得分、命中 |
| 红 | `#ff4040` | 倒计时、蜂鸣、警告 |
| 夜 | `#04050a` / `#0a0e18` | 底 |

## 3. 动作

- **投篮**：一律用游戏的 `shotCurves(ph)` → `poseGuy(guy, c)`，ph 0→1.2，高度 `+ max(0, jmp·0.55 − over·0.55)`，和实机同一条曲线。
- **非投篮姿势**（运球、接球、举手庆祝、防守）：直接写关节角，符号约定照游戏：
  - `arms[i].rotation.x` 负 = 前抬，−2.6 ≈ 举过头
  - `elbows[i].rotation.x` 负 = 屈肘
  - `legs[i].rotation.x` 负 = 屈髋，`knees[i].rotation.x` 正 = 屈膝
  - `g.rotation.x` 正 = 后仰
- **慢动作**：只改 ph 的推进速度，不改曲线。
- **Hold**：重拍后停 2–4 帧。

## 5. 可复现渲染

游戏本身是实时循环，不能直接录。做法：

1. 无头 Chromium 打开 `index.html?trailer=1`，**启动前把 `Math.random` 换成固定种子**，保证每个渲染进程搭出一模一样的观众和场景。
2. 启动后冻结游戏的 `requestAnimationFrame`，由导演脚本逐帧驱动：摆姿势 → 更新观众/火焰/彩带/球网 → `renderer.render`。
3. **按镜头分配给渲染进程**：每个镜头开始时重置随机种子和特效状态，从镜头首帧顺序模拟，所以任何进程渲染同一个镜头结果都一样。
4. 2D 合成层放大、加 HUD、扫描线，JPEG 管道进 ffmpeg，和合成音轨混流。
