# v2.23.0 连续水流、电线与球员做工升级

## 用户目标与当前基线

用户授权先修雨林瀑布/湘南电线，再升级发型、球衣、球鞋和关节融合，直接实施并做游戏画面验证。保留 Minecraft 风格。当前 main 的运行版本是 v2.22.0，工作区已有另一位 AI 未提交的街区收紧、湘南重排、相机与传球修正；全部保留。备份：`backup/flow-player-20260910/pre-v2.23.0.tar.gz`。

## 执行顺序与技术方案

1. 瀑布：移除中段截断岩台，统一为崖顶到水潭的一张连续水幕；水纹按下落距离对应的飞行时间平流，越往下越快，底部才出现水雾/白沫。保留峡谷布局与镜头通道。
2. 电线：按相邻杆的真实高度插值，再叠加中部下垂；替换目前每段分别从两根杆高度计算导致的跳变，构建连续曲线管网格，端点严格落在绝缘子上。横屏、竖屏和近景检查连续性。
3. 球员关节：保留全部骨骼与拾球坐标，调整网格轮廓与重叠深度；膝肘比相邻肢段略窄，去掉突出的独立膝盖贴块，肩部融入上臂。检查站立、深屈膝、举球、出手和跑动，不只看静态。
4. 球衣：清理多重领口、肩条、下摆与角色专属叠层，建立一件主衣身、薄滚边和单一下摆；纹理表达织物、缝线与号码，减少几何装甲感。帽衫/换装隐藏与恢复必须正常。
5. 发型：保留发根固定、发梢微动结构；缩小大球状卷发，组织连续发冠、渐层侧发和有方向的发束。覆盖所有已有发型，不改脸。
6. 球鞋：收整鞋面/中底与鞋头叠层，整理鞋舌、细鞋带、后跟支撑和装备特征；保持脚掌/前掌分段绑定，鞋底不穿地。
7. 验证：静音浏览器留同机位改前后图；两场动态连续性、全角色造型与四种鞋、更衣室替换、跑动/投篮/扣篮、第一人称、桌面/触屏、资源回收；结构检查与版本快照同步。实际手机帧率单列，不以模拟替代。
