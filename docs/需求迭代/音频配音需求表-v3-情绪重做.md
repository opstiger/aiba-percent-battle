## 0. 核心复盘：为什么必须升级到 Gemini 最先进音频生成模型？

反馈指出的问题：*“根本没有情绪，没有拖长音，没有短音，没有笑声、叫声，没有观众反馈。”*

根源在于之前使用的 Edge-TTS 等传统播报模型，设计定位是平稳播报，**在物理架构上无法输出极端情绪（破音爆喊、带笑声挑衅、长达 3 秒的元音拉长、激烈喘息）**。

### v3 终极重做三大变革：
1. **全面切换到 Gemini 最新原生音频模型（Gemini 2.0 / 2.5 Audio Output）**：
   * 原生支持大模型级的端到端情感控制，精准理解 Prompt 中的 `[screaming]`、`[cracking voice]`、`[burst of laughing]`、`[whispering]`、`[breathless gasping]` 等语气指令。
   * 采用 Gemini 专属高表现力音色库：`Puck`（高燃DJ）、`Fenrir`/`Charon`（霸气核心）、`Vindemiatrix`/`Algenib`（搞怪与挑衅对手）、`Sadachbia`/`Kore`（转播PA）。
2. **强制划分 S / M / L 三档时长与节奏反差**：
   * **S 档（短促爆点 0.35~0.8s）**：如 `BANG!`、`BLOCKED!`、`COUNT IT!`，绝不说完整长句。
   * **M 档（常规叙述 1.0~1.8s）**：战术交代、分球播报。
   * **L 档（拖长音 2.0~3.5s）**：绝杀命中、加时咆哮、超远三分。
3. **多轨复合混音架构（Layered Multi-Track Audio）**：
   * 彻底告别单轨随机切换，游戏端实现 **人声 (Voice) + 观众声浪 (Crowd) + 非语言语气 (Vox)** 三轨同步激发。

## 7. 游戏端多轨复合播放与避让（Ducking & Concurrency）架构

### 7.1 多轨复合触发配置规范 (`src/audio.js`)
为支持 `Voice`、`Crowd`、`Vox` 同时发声，`AUDIO_EVENTS` 升级为复合对象结构：

```javascript
const AUDIO_EVENTS = {
  lastshot_make: {
    voice: ["dj_lastshot_make_l01_en.mp3", "dj_lastshot_make_s01_en.mp3"],
    crowd: ["crowd_eruption_l01_en.mp3", "crowd_eruption_l02_en.mp3"],
    vox:   ["vox_scream_joy_l01_en.mp3"]
  },
  lastshot_blocked: {
    voice: ["dj_ls_block_s01_en.mp3"],
    crowd: ["crowd_groan_l01_en.mp3"],
    vox:   ["vox_laugh_taunt_s01_en.mp3"]
  }
};

// 引擎底层同时触发三个 AudioNode，并在 WebAudio Bus 动态混音
function playCompositeAudioEvent(eventId, opt) {
  const ev = AUDIO_EVENTS[eventId];
  if (!ev) return;
  if (ev.voice) playVoiceRandom(ev.voice, opt);
  if (ev.crowd) playCrowdRandom(ev.crowd, { volume: 0.8 });
  if (ev.vox)   playVoxRandom(ev.vox, { volume: 0.9 });
}
```

### 7.2 中断避让策略 (Ducking Rules)
1. **S 档最高优先级（Highest Preemption）**：当封盖、出手、进球触发时，立即以 `80ms` 线性淡出正在播放的任何长背景语音。
2. **刷网留白原则（Swish Cleanliness）**：球进网瞬间的 `swish.mp3` 所在频率（2kHz~5kHz）独占通道，人声自动避让 3dB，凸显清脆击网质感。

## 8. Gemini API 自动化生成执行脚本

使用 `google.genai` SDK 调用 Gemini 2.0 / 2.5 Flash 原生音频生成端点：

```python
from google import genai
from google.genai import types

client = genai.Client(api_key=os.environ.get("GEMINI_API_KEY"))

response = client.models.generate_content(
    model='gemini-2.0-flash',
    contents=f"Perform this basketball commentary line with {spec['emotion']}: \"{spec['text']}\"",
    config=types.GenerateContentConfig(
        response_modalities=["AUDIO"],
        speech_config=types.SpeechConfig(
            voice_config=types.VoiceConfig(
                prebuilt_voice_config=types.PrebuiltVoiceConfig(voice_name=spec['voice'])
            )
        )
    )
)
```
