# Foot-to-Shoe fitting standard · 灰模实验 v0.1

本轮只做 ShoeFitAnchor + ShoeLastDebug。正式游戏仍为 v2.26.0，index 未引用实验脚本；basketball-shoes.js、characters.js、motion.js 和 shot-motion.js 未改。实验入口由 scripts/shoe-last.test.mjs 在静音浏览器中注入 tools/shoe-fit-lab.js，不把实验鞋装回正式游戏。

## 结构

footRig → ShoeFitAnchor → ShoeLastDebug。ankle / footRig / toeJoint 及原有父子关系完整保留。现有脚左右朝向由 footRig 继承；本轮鞋楦左右对称，不使用额外负缩放。未来非对称鞋楦应在设计层镜像网格，避免与角色负缩放重复。

ShoeFitAnchor 只含 fitting：length 整体缩放、groundOffset 位置、yaw 朝向；设计层只读取 L=1 的归一化截面，不读取旧脚 bounding box。角色 root 的 scale 自然继承，三个 L 指角色本地长度，不能把世界缩放再乘第二遍。

ShoeLastDebug 是一个灰色封闭网格，124 triangles / 1 material。没有鞋舌、鞋带、鞋帮、Logo、色块、复杂底或具体鞋型。高帮 .46L 仅在额外参考图画水平虚线。底厚 .11L 为内部设计基准虚线，本轮没有另建外底/中底模块；不能把鞋楦当作已完成篮球鞋。

## 旧脚部视觉处理清单

|对象|实验穿鞋状态|原因|
|---|---|---|
|footRig 内所有旧鞋 Mesh，包括当前 RetroHigh|隐藏，保存原显隐状态|不参与鞋楦设计、不叠鞋|
|toeJoint 内前掌、圆头、中底等 Mesh|隐藏|toeJoint 节点仍保留并继续接收原动画|
|ankleBlend|隐藏并替换为 shoeEquippedAnkleProxy|原 .158 宽连接块不撑大新鞋口|
|sockKnit 装饰网格|隐藏|原踝袜装饰不适合新代理|
|crewSock / sockStripe|隐藏原件，替换为下端收窄的视觉代理|防止袜子和方形小腿互穿；代理沿用原高度和颜色|
|legacySock|保持被隐藏；恢复时回到进入实验前状态|不叠旧短袜|
|calf|隐藏原件，以复制几何替代并只渐变收窄下端|保留原骨骼和上端轮廓；不通过扩大鞋来容纳旧小腿|
|膝关节、膝套、大腿、全套骨骼节点|保留|不属于鞋楦替换范围|

不调用正式鞋系统 clear，避免改变其装备状态。实验 clear 只释放本实验代理/鞋楦几何和复制材质，并恢复记录的可见性；不会销毁原网格、材质或纹身贴图。重复三种 L 切换和最终恢复均检查。

## 接地职责

原动画的接地基准基于旧鞋。新鞋楦在蓄力时会出现约 8–17mm 下沉，不能改骨骼或扩鞋解决。sync() 在明确接地的脚上，把 world groundY 转换为 footRig 的局部 Y 偏移，只移动 ShoeFitAnchor；不动角色根、腿、踝、footRig 或 toeJoint。

起跳保持基准偏移、不拉向地面。跑动截图仅第一只脚为支撑脚；将来运行时接入必须使用实际 runFootSupport/physics 状态，并加入时间连续的接触混合，本次未接入正式动画循环。不能把若干静帧接地通过宣称完整动态适配已完成。

## 验证和评审

运行：启动本地 4195 静态服务后 node scripts/shoe-last.test.mjs。浏览器启动即静音，并 finally 关闭。输出 artifacts/shoe-last-20260915/review.html、report.json、ShoeLast_L1.object.json、4 视图、参考高度图，以及 3L × 7 姿态（正面/侧面/背面/蓄力/起跳/落地/跑动）。同一角色、同一相机、同一姿态参数，每次还原骨骼初始变换，避免前一次跑动污染后续尺寸。

检查包括归一化长宽高、apply 和 sync 前后骨骼变换/父节点一致、接地姿态底部误差、离地姿态不贴地、脱下恢复旧网格显隐、源码 SHA256 未变。
